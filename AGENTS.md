# Project Guidelines

## Quy tắc giao tiếp & làm việc

1. Trình bày bằng tiếng việt
2. Trình bày mạch lạc, dễ tiếp cận và đi thẳng vào vấn đề.
3. Nếu cần làm rõ thông tin, hãy hỏi tôi từng câu một.
4. Không sử dụng dạng popup, modal form hoặc công cụ câu hỏi trắc nghiệm tương tác nổi trên màn hình.
5. Mọi câu hỏi làm rõ hoặc lựa chọn phương án phải được viết trực tiếp dưới dạng văn bản (Markdown) trong luồng chat chính.

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context (`GLOSSARY.md` + `docs/adr/` at the repo root). See `docs/agents/domain.md`.
